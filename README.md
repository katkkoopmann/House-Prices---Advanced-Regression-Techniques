# Technical Challenge

## English Version

This repository contains a Jupyter Notebook that performs data analysis and modeling as part of a technical challenge.

### Features
- **Data Cleaning**: Handling missing values and standardizing the dataset.
- **Exploratory Data Analysis (EDA)**: Understanding patterns and trends in the dataset.
- **Feature Engineering**: Selecting and transforming features to improve model performance.
- **Model Training**: Implementing machine learning models such as Decision Trees, Random Forest, and Logistic Regression.
- **Evaluation**: Comparing models using accuracy, precision, recall, and confusion matrices.

### Dataset
- The dataset contains structured information used for predictive modeling.
- It includes multiple features that influence the target variable.

# Desafío Técnico

## Versión en Español

Este repositorio contiene un Jupyter Notebook que realiza análisis de datos y modelado como parte de un desafío técnico.

### Características
- **Limpieza de Datos**: Manejo de valores nulos y estandarización del conjunto de datos.
- **Análisis Exploratorio de Datos (EDA)**: Identificación de patrones y tendencias en los datos.
- **Ingeniería de Características**: Selección y transformación de variables para mejorar el rendimiento del modelo.
- **Entrenamiento de Modelos**: Implementación de modelos de aprendizaje automático como Árboles de Decisión, Random Forest y Regresión Logística.
- **Evaluación**: Comparación de modelos utilizando métricas como exactitud, precisión, recall y matrices de confusión.

### Conjunto de Datos
- El dataset contiene información estructurada utilizada para modelado predictivo.
- Incluye múltiples variables que influyen en la variable objetivo.
